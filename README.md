# Trench — the daily dive

7 prompts · 25 seconds each · rarer answers sink deeper.

Play: https://lojsifjosidjfoijfoij.github.io/trench/

- `index.html` — the game (also runs as a claude.ai artifact)
- `bank.js` — backup prompt bank
- `sets/*.js` — the pre-written daily dives, one `add([...])` per day from 2026-09-24
- `tools/build.js` — validates every answer list and builds the site into `docs/` (`node tools/build.js`)
- `tools/icons.py` — home-screen icons
